# Speech-to-Text Transcription Tool

A Python-based speech recognition application that converts audio recordings into readable text.

## About the Project

This project allows users to upload audio recordings and automatically convert spoken words into text using speech recognition technology.

## Features

- Upload audio recordings.
- Supports English and Hindi transcription.
- Converts speech into readable text.
- Displays transcription results.
- Download transcripts as TXT files.
- Simple and user-friendly interface.

## Technologies Used

- Python
- Streamlit
- SpeechRecognition Library
- Google Speech Recognition

## Installation

1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
streamlit run app.py
```

## How It Works

1. User uploads an audio recording.
2. The application reads the audio.
3. SpeechRecognition processes the audio.
4. Google Speech Recognition identifies spoken words.
5. The converted text is displayed and can be downloaded.
